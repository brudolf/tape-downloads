# TAPE desktop releases

TAPE is a free native desktop application that records, searches and replays your AI coding sessions. Your recordings stay on your computer.

Download official packages from [Releases](https://github.com/brudolf/tape-downloads/releases). Each release lists only its validated OS packages. Beta builds are explicitly marked and may require additional installation steps; read their release notes.

[Download page](https://tape-1l7.pages.dev/download/) · [Magyar](https://tape-1l7.pages.dev/hu/download/). The planned custom domain is tapeapp.hu.

This repository distributes compiled applications, SHA-256 checksums and build provenance. It contains no application source code or user recordings. GitHub's automatic source archives contain only this distribution README.

The Mac package is a Universal DMG for Apple Silicon and Intel. Windows uses a portable x64 ZIP; Linux uses a portable x86_64 tar.gz. New Windows/Linux packages are deferred. The website preserves each OS's latest published version independently and separates stable from beta downloads.
